# 00 · PRD v0.1 — 选择题答题系统

- 版本：v0.1（草案，待 G1 冻结）　作者：PM-Spec（bootstrap 阶段由 Lead 代行）　日期：2026-11-08

## 1. 背景与目标

单机构（学校/培训）需要一个可上线的在线选择题考试系统，替代“发卷-收卷-人工判分”的低效流程。V1 目标：教师可在 30 分钟内完成“建题库 → 组卷 → 发考试”，学生在线限时作答并当场拿到成绩，管理员可审计关键操作。

**成功判据（G4/G5）**：
1. 一条完整链路可演示：登录 → 建题 → 组卷 → 发布 → 学生作答 → 自动判分 → 成绩/错题本；
2. 权限负例全部拒绝（学生不能看他人成绩、不能改题库）；
3. 重复交卷、断网恢复、到时自动交卷三类异常不产生错误数据。

## 2. 用户角色

| 角色 | 描述 | 核心诉求 |
|---|---|---|
| 学生 student | 被安排参加考试的人 | 稳定作答、不丢答案、看到成绩与错题 |
| 教师 teacher | 建题库、组卷、发考试、看班级成绩 | 快、批量、少手工 |
| 管理员 admin | 管账号、权限、审计、数据备份 | 可控、可追溯 |

## 3. 范围

### 3.1 范围内（MUST / P0）

| ID | 功能 | 说明 |
|---|---|---|
| F1 | 账号与 RBAC | 登录/登出/会话过期；学生/教师/管理员三种角色；账号停用即时生效 |
| F2 | 题库管理 | 单选/多选/判断题 CRUD；标签、难度、解析；Excel/CSV 批量导入（幂等去重）；软删除 |
| F3 | 组卷 | 从题库选题、每题分值、多选给分规则；试卷版本冻结后不可变 |
| F4 | 考试会话 | 发布考试（时间窗、时长、题序/选项乱序）；学生开始考试；自动保存；断线恢复；幂等交卷；到时自动交卷 |
| F5 | 自动判分 | 提交时事务内判分落库；多选支持全对给分/部分给分；成绩只读 |
| F6 | 成绩与错题本 | 学生看自己的成绩与逐题结果；错题本按题去重统计错误次数；教师看考试汇总 |
| F7 | 审计与管理 | 管理员管账号；所有写操作落审计日志；审计查询限管理员 |

### 3.2 范围外（WON'T，V1 不做）

多租户 SaaS、主观题 AI 判分、在线监考/摄像头、移动 App、消息推送、SSO/微信登录、题库智能推荐。

### 3.3 优先级与砍单顺序

- **P0（不可砍）**：F1、F2、F3、F4、F5，以及 G4 判据。
- **P1（可延后）**：F6 的教师汇总视图、成绩导出。
- **P2（先砍）**：F6 错题本、F7 管理后台页面、统计图表。
- 砍单触发：D6 时 G3 未通过 → 按 P2 → P1 顺序砍，主链路不缩。

## 4. 功能需求与验收标准

> 每条 AC 必须可被 E2E 或接口测试映射（R5 在 `docs/60-test-plan.md` 中给出用例号）。

### F1 账号与 RBAC

- **AC-01**（接口）：Given 已存在教师账号，When 用正确密码登录，Then 返回 200 与用户信息，并下发 HttpOnly 会话 Cookie。
- **AC-02**（接口）：Given 登录名存在但密码错误，When 登录，Then 返回 401，响应体不区分“账号不存在/密码错误”。
- **AC-03**（接口）：Given 学生已登录，When 调用 `GET /api/users`，Then 返回 403 且不泄露用户数据。
- **AC-04**（接口）：Given 管理员停用某账号，When 该账号 8 小时内再次请求，Then 返回 401（会话即时失效）。

### F2 题库管理

- **AC-05**（E2E）：Given 教师已登录，When 新建含题干/选项/答案/解析的单选题并保存，Then 列表出现该题且字段完整。
- **AC-06**（接口）：Given 导入文件含 1 行错误（缺答案），When 导入，Then 返回部分成功：成功条数 + 失败行号与原因，成功行已入库。
- **AC-07**（接口）：Given 题目已被试卷引用，When 删除该题，Then 返回 409 `QUESTION_IN_USE`，不执行物理/软删除。
- **AC-08**（接口）：Given 同一导入文件重复提交两次，When 第二次导入，Then 不产生重复题目（按“题干+类型”幂等去重）。

### F3 组卷

- **AC-09**（E2E）：Given 题库有 ≥10 题，When 勾选 10 题并设置分值（合计 100），Then 保存成功且返回总分 100。
- **AC-10**（接口）：Given 试卷已用于已发布考试，When 修改试卷题目或分值，Then 返回 409，旧考试数据不受影响（考试持有试卷快照）。

### F4 考试会话

- **AC-11**（接口）：Given 考试未到开始时间，When 学生创建会话，Then 返回 409 `EXAM_NOT_STARTED`。
- **AC-12**（E2E）：Given 学生正在作答，When 断网 30 秒后恢复并保存，Then 已答内容不丢且可继续交卷。
- **AC-13**（接口）：Given 会话已提交，When 同一会话再次提交，Then 幂等成功（返回同一成绩），不重复计分、不产生第二条成绩记录。
- **AC-14**（接口）：Given 考试时长到达，When 学生继续请求保存，Then 返回 409 `EXAM_EXPIRED`，服务端自动生成已提交状态并判分。
- **AC-15**（接口）：Given 会话进行中，When 以 `client_seq` 较小的保存请求覆盖较新答案，Then 服务端拒绝覆盖（仅接受更大 seq）。

### F5 自动判分

- **AC-16**（接口）：Given 单选/判断题，When 提交答案，Then 正确得满分、错误得 0。
- **AC-17**（接口）：Given 多选题配置“全对给分”，When 少选或错选，Then 得 0；Given 配置“部分给分”，When 少选且无错选，Then 按 `选中正确数/正确总数 × 分值` 计算（保留 2 位小数）。

### F6 成绩与错题本

- **AC-18**（接口）：Given 学生 A 已完成考试，When 学生 B 请求 A 的 result，Then 返回 403。
- **AC-19**（接口）：Given 学生未交卷，When 请求 result，Then 返回 409 `NOT_SUBMITTED`。
- **AC-20**（接口）：Given 同一学生同一题错误两次，When 查看错题本，Then 该题只出现一次且 `wrong_count=2`。

### F7 审计与管理

- **AC-21**（接口）：Given 教师已登录，When 查询审计日志，Then 返回 403；管理员查询则返回近 180 天记录。
- **AC-22**（接口）：Given 任意写操作，When 完成后查审计日志，Then 存在记录且含 actor/action/target/ip/时间。

| 项 | 指标 | 验证方式 |
|---|---|---|
| 作答性能 | 100 并发下保存/读取接口 P95 < 300ms | T3.4 性能冒烟 |

| 可用性 | 单机 Compose + 健康检查，目标 99% | T4.4 监控 |

## 6. 假设（G1 一次性确认）

| 编号 | 假设 | 默认值 | 若变化的影响 |
|---|---|---|---|
| A1 | 题型 | 单选/多选/判断；多选支持全对/部分给分两档 | 判分契约与题库 schema 变更，需 ADR |
| A2 | 导入格式 | Excel/CSV 模板 + JSON 备份导出；不做 Word 解析 | 仅 F2 任务卡调整 |
| A3 | 规模 | 单机构、约 500 学生、同时在线 ≤100 | 性能阈值与容器规格，不影响架构 |
| A4 | 账号 | 本地账号 + 教师建号/邀请码；不接 SSO | 仅 F1 任务卡调整 |

## 7. 术语

- **题库（question bank）**：题目集合，支持标签/难度/解析。
- **试卷（paper）**：从题库选出的一组题 + 每题分值 + 给分规则，冻结后不可变。
- **考试（exam）**：试卷 + 时间窗 + 时长 + 乱序配置，可发布/关闭。
- **会话（exam session）**：某学生参加某次考试的一次尝试，`(exam_id, student_id)` 唯一。
- **快照（snapshot）**：考试发布时冻结的试卷内容，保证后续改题不影响历史成绩。
